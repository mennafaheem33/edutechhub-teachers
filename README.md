# EduTech Hub — AI & EdTech Tools for Teachers 🎓

Discover, filter, and access the best AI and EdTech tools for education. Designed for teachers, curriculum developers, and educational content creators.

**Live Reference**: [edutechhubforteachers.lovable.app](https://edutechhubforteachers.lovable.app/)

---

## 🌟 Key Features

- **🛠️ 213+ Curated EdTech & AI Tools**:
  - Filterable by **18 Subjects** (*Arabic, English, Math, Science, ICT, Art, Religion, etc.*).
  - Categorized by **15 Creation Goals** (*Lesson Planning, Quizzes & Worksheets, Presentation, Image Generation, Video Generation, Story Book Creation, Text to Speech, Lip Sync, VR & AR, Gamification, Prompt Maker, Courses*).
  - Target grade level badges (*KG & Lower Grades*, *Upper Grades*, *All Grades*).
- **📋 Teacher Prompt Library**:
  - 23 ready-to-use AI prompts for lesson plans, weekly unit outlines, differentiated teaching, assessments, exit tickets, and classroom activities.
  - 1-click prompt copying with instant feedback.
  - Dedicated pages for every prompt template (`/prompt/:slug`).
- **🔍 Live Autocomplete Search**:
  - Real-time instant search in the header across both tools and prompts with dual-section dropdown results.
- **🌍 Bilingual English & Arabic (with RTL)**:
  - Seamless full-site translation between English and Arabic with native Right-to-Left (RTL) layout switching and persistent preference.
- **🌙 Dark & Light Themes**:
  - Educational color palette with custom HSL design tokens, persistent theme state, and matching vector logos.
- **🚀 Azure App Service Ready**:
  - Built-in production Node.js SPA server (`server.js`) and IIS configuration (`web.config`).

- **Framework**: [React 19](https://react.dev/) + [Vite 8](https://vite.dev/)

- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Routing**: [React Router v7](https://reactrouter.com/)
- **Production Server**: Node.js HTTP Server (`server.js`)

## 🚀 Getting Started

### Prerequisites

- Node.js (v20+ LTS recommended)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/mennafaheem33/edutechhub-teachers.git
cd edutechhub-teachers

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit [http://localhost:5173](http://localhost:5173) in your browser.

---

## 📦 Building for Production

```bash
# Type check and build Vite bundle
npm run build

# Start local production server
npm start
```
